# BCG Literature, Benchmarks, and Tool Status

## Practical task split

| Task | Literature direction | Public benchmark status | Current implementation | Status |
| --- | --- | --- | --- | --- |
| Heart-rate / J-peak detection | Local maxima, template matching, Hilbert/phase-vocoder, wavelet/CWT, and newer Transformer/set-prediction models. | Figshare 2025 bed BCG includes 46 subjects with paired ECG and heartbeat files; Bed-Based BCG dataset includes ECG/PPG/BP. | `BCG_detect_j_peaks` now runs multiple candidates and selects by spectral HR consistency plus interval regularity. `scripts/evaluate_bcg_figshare_hr.py` evaluates against heartbeat annotations. | Reproduced smoke benchmark: 46 subjects x 60s, HR MAE 10.04 bpm, median AE 2.88 bpm, within-5-bpm 0.614; a 12-subject smoke subset reached HR MAE 4.37 bpm. |
| HRV / recovery / stress features | Derived from beat-to-beat intervals; literature treats BCG HRV as useful but sensitive to J-peak error. | Same paired ECG/heartbeat datasets can validate interval error; stress labels are usually not BCG-only public. | `BCG_compute_hrv` computes SDNN/RMSSD/pNN50 and limited Welch LF/HF proxy. | Proxy, not ECG-equivalent. |
| Respiration rate | Respiratory-band baseline motion, cardiac amplitude modulation, Hilbert transform. | Bed BCG datasets often include respiration or can compare to PSG/resp channels when available. | `BCG_estimate_respiration` combines baseline respiratory band and Hilbert cardiac-envelope modulation. | Implemented proxy; needs reference-resp benchmark next. |
| Sleep monitoring / sleep stage | HRV/RRV/motion features, stacked ensembles, XGBoost/attention, and large proprietary BCGNet-style models. | Some BCG sleep datasets/code are public or semi-public; many SOTA results use private data. | `BCG_estimate_sleep_features` exposes sleep-wake compatible features and a conservative proxy. | Not full sleep staging until labeled PSG/BCG benchmark is wired. |
| AF / rhythm abnormality | Wavelet+ML, multi-scale attention, residual CNN; reported high performance on private inpatient sleep BCG cohorts. | Public BCG AF benchmark is limited; Figshare has diagnostic and heartbeat labels but needs diagnosis parsing and split design. | `BCG_screen_arrhythmia` returns interval-irregularity risk only. | Auxiliary screen, not diagnostic. |
| Bed presence / movement artifact | Energy thresholds, motion burst detection, sensor quality gating. | Can be evaluated with bed occupancy annotations if available; otherwise useful as QC. | `BCG_assess_bed_presence_motion`. | Implemented QC/proxy. |
| Blood pressure | PTT/morphology models and BCG mechanism-based decomposition; needs subject/device calibration and BP reference. | Bed-Based BCG dataset has ECG/PPG/BP; useful next benchmark. | `BCG_estimate_bp_proxy` exposes calibrated baseline and relative variation only. | Not absolute BP without calibration. |
| Heart failure / cardiac function | Longitudinal mechanical morphology/contractility features; clinical validation requirements are high. | No simple public BCG-only SOTA benchmark found for deployable diagnosis. | Routed to HRV/BP/morphology proxy with `standalone_supported=False`. | Research-only. |

## Local benchmark results

- HR/J-peak, Figshare 46 x 60s: HR MAE 10.04 bpm, median AE 2.88 bpm, within 5 bpm 0.614. The main failures are harmonic/over-detection cases; `BCG_detect_j_peaks` now exposes `harmonic_ambiguity` and candidate HR spread.
- BCG-AF proxy benchmark, Figshare 46 x 60s: parsed 17 AF-positive and 29 AF-negative subjects from `Overall_info.xlsx`; `BCG_screen_arrhythmia` irregularity score AUROC 0.655, average precision 0.456, balanced accuracy 0.690 at threshold 0.65. This supports routing/weak screening only.

## PSG-labeled BCG benchmark audit

I checked candidate PSG/BCG sleep-stage datasets and code paths. As of this audit, no directly usable public benchmark with synchronized raw BCG and 30s PSG hypnogram labels was confirmed. The 2025 Engineering Applications of Artificial Intelligence paper reports 10 recordings / 10,614 segments and points to `https://github.com/ZJSRU-ICLaboratory/BCG-Sleepstaging`, but GitHub API and `git clone` currently return 404, so it is a SOTA reference rather than a reproducible benchmark. The Mendeley “Ballistocardiography sleep dataset” is public BCG but its labels are subject IDs, not PSG sleep stages, so it must not be used for sleep-stage training.

The machine-readable audit is generated by `scripts/catalog_bcg_psg_sleep_benchmarks.py` and written to `/data1/jiahui/biosignal-agent/datasets/processed/bcg_sleep_benchmark_catalog.json`. If synchronized BCG + PSG hypnogram labels are obtained later, `scripts/train_bcg_sleep_stage_from_manifest.py` trains a subject-held-out feature ensemble from a manifest with `record, signal_path, sampling_rate, stage_path`.
