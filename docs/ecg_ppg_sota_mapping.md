# ECG/PPG SOTA And GitHub Mapping

This note tracks which ECG/PPG BioSignalAgent tools are backed by local models, public-code methods, or proxy wrappers. It is intentionally conservative: clinical-use claims require external validation and dataset-specific calibration.

### ECG optimization update - rhythm/AF, apnea, morphology/ST

- `ECG_classify_rhythm_segment` and `ECG_detect_afib` now default to a MITDB rhythm + partial MIT-BIH AFDB feature classifier. AFDB uses `atr` rhythm annotations and `qrs` beat annotations. Grouped CV improved AF F1 from 0.592 to 0.711 and AF recall from 0.661 to 0.862 on 3431 windows. The small 240-window MITDB smoke benchmark reaches AF F1 0.962, but that is treated only as an in-domain smoke result.
- `ECG_screen_sleep_apnea` now uses the mixed Apnea-ECG + UCDDB + SLPDB sequence-context CNN-BiLSTM for long ECG segments. This lowers headline in-domain score versus the Apnea-ECG-only model, but is more realistic: grouped CV F1 0.551 / AUROC 0.748 overall, with source F1 0.706 on Apnea-ECG, 0.484 on UCDDB, and 0.521 on SLPDB.
- `ECG_analyze_qt_interval`, `ECG_screen_conduction_block`, and `ECG_screen_ischemia_st` now attach QTDB U-Net delineation evidence in addition to NeuroKit/DWT interval proxies. QTDB U-Net event-level scoring is still weak for T waves, so QT/ST outputs remain screening evidence rather than SOTA morphology diagnosis.

### ECG AF binary-detector update

`ECG_detect_afib` is now decoupled from the multiclass rhythm wrapper. A binary AF feature classifier trained on MITDB rhythm windows plus partial MIT-BIH AFDB is the primary AF probability backend. Grouped CV: F1 0.728, recall 0.840, precision 0.642, AUROC 0.974. A larger 3-record AFDB expansion was tested but did not improve F1 because added windows were strongly normal-heavy; it is retained as an experiment, not the default.

### ECG sleep-apnea short-window update

`ECG_screen_sleep_apnea` now uses mixed-dataset ECG apnea backends for both short and long inputs. The 60-second RR/EDR CNN-BiLSTM was retrained on Apnea-ECG + UCDDB + SLPDB. Grouped CV: F1 0.522, AUROC 0.716 overall; source F1 0.606 on Apnea-ECG, 0.484 on UCDDB, and 0.509 on SLPDB. This is lower than the previous Apnea-ECG-only short-window F1, but it is the more realistic default for user-provided ECG.

### ECG ST/ischemia update

`ECG_screen_ischemia_st` now has an EDB-backed ST abnormality classifier. European ST-T Database annotations are parsed as channel-specific ST episode starts/ends plus AST peak displacement notes, exported into 60-second lead windows, and used to train an ST feature classifier. The first 6-record EDB model reached record-heldout F1 0.687 / AUROC 0.869, but external testing on six additional EDB records dropped to F1 0.171, showing record overfit. The default was therefore switched to the broader 12-record EDB model: 3840 windows, 309 ST-abnormal windows, record-heldout window F1 0.590 / AUROC 0.860. A new `scripts/evaluate_ecg_st_episode_scoring.py` scorer merges positive windows into ST episodes; record-heldout OOF episode scoring for the 12-record model gives episode F1 0.673, precision 0.587, recall 0.787 at the default 0.94 threshold. This sacrifices some held-out window F1 for more realistic record coverage and better episode-oriented reporting, replacing pure normalized J-point thresholding as the default ST/ischemia evidence path while retaining the J-point proxy and QTDB delineation evidence as supporting context.

PTB-XL is now used as an additional benchmark anchor for ECG conduction/ST-T superclass screening from lead II. A fold-balanced 329-record PTB-XL subset was prepared from 100 Hz waveforms (`scripts/prepare_ptbxl_superclass_dataset.py`) and trained with feature classifiers (`scripts/train_ecg_ptbxl_superclass_feature_classifiers.py`). Lead-II CD/conduction classifier: F1 0.730, AUROC 0.836. Lead-II STTC classifier: F1 0.753, AUROC 0.885. A larger 707-record fold-balanced subset was then trained; STTC improved slightly to F1 0.765 / AUROC 0.883, while CD fell to F1 0.707 / AUROC 0.838. The default therefore uses the 329-record CD model and the 707-record STTC model. `ECG_screen_conduction_block` now emits PTB-XL CD probability in addition to PR/QRS interval proxies. `ECG_screen_ischemia_st` now emits PTB-XL STTC probability as broad ST/T-abnormality evidence, but keeps the EDB episode classifier as the more ischemia/ST-specific backend. A lead-II ResNet experiment (`scripts/train_ecg_ptbxl_superclass_1dcnn.py`) did not improve the default backend: CD F1 0.618 / AUROC 0.737 and STTC F1 0.734 / AUROC 0.841. A 12-lead ResNet experiment (`scripts/train_ecg_ptbxl_superclass_12lead_cnn.py`) on the same 329-record manifest also underperformed the feature baseline: CD F1 0.649 / AUROC 0.758 and STTC F1 0.695 / AUROC 0.784. Feature classifiers remain default until a larger/full 12-lead deep model is trained.
